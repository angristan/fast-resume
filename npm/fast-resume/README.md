# fast-resume

Search and resume conversations across coding agents from one terminal UI.

```bash
npm install --global fast-resume
fr
```

This package installs the native `fast-resume` binary for the current platform. Supported platforms are Windows x64, macOS ARM64/x64, and Linux glibc ARM64/x64.

See the [fast-resume repository](https://github.com/angristan/fast-resume) for usage and documentation.
